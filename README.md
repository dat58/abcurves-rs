# abcurves-rs

A pure-Rust port of the [ABCurves](https://github.com/optima-manent/ABCurves) inference
runtime: human mouse movement generated one millisecond at a time.

The crate covers the Continuous Planner, the Static Planner, and the fixed-point
Renderer. Training, evaluation and dataset tooling stay in the Python project.
